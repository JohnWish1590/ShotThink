Capture. Annotate. Ask.

A Chrome extension that sends a browser screenshot straight into your own ChatGPT conversation. Capture a region, mark it up, and it lands in a dated chat with your standing instructions attached.

Download for Chrome View source

Free. No API key, no subscription, no per-request billing. MIT licensed.

Why it costs nothing

ShotThink does not call the OpenAI API. It drives the ChatGPT page you are already signed in to: it picks the file input, writes your instructions into the editor, and clicks send.

So it spends whatever your existing subscription already covers, instead of billing you per token. There is no key to obtain and nothing to top up.

The trade-off is that delivery depends on ChatGPT's page structure and on a background tab staying open. Every guard in the tool exists because of that.

What it does

Everything a screenshot tool needs, nothing it does not.

⌗

Region capture

Pixel-accurate at any display scaling, including 125% and 150% Windows scaling.

✎

Six annotation tools

Rectangle, ellipse, arrow, pen, text and mosaic, with undo. Colours and font size are remembered.

T

Text that previews itself

Opens where your mouse is, wraps at the selection edge, and draws exactly as it looked while typing.

⤓

Long capture

Scrolls the page and stitches by exact scroll position. Sticky headers are suppressed so they do not repeat.

◷

One chat per day

Each day gets a conversation named YYYY-MM-DD. Later captures append to it, numbered.

◧

Selected text

Right-click any selected text → Send to AI. No clipboard reading, no global keyboard hooks.

Install

ShotThink is not on the Chrome Web Store — it automates a third-party site, which is a poor fit for store review. Installing it takes about a minute.

  1. Download and unzip ShotThink-1.0.0.zip into a folder you will keep.
  2. Open chrome://extensions/ and turn on Developer mode in the top right.
  3. Click “Load unpacked” and select the folder you unzipped.
  4. Sign in to chatgpt.com in the same browser profile. ShotThink uses that session; it never reads your credentials.
  5. Press Alt+Shift+S or click the toolbar icon. Ctrl+Shift+S is reserved by Chrome for “Save page as”, so it cannot be used.

Safety

These are not edge cases bolted on afterwards. They are the reason the tool is usable at all.

A send whose outcome is unknown is never retried automatically. It is marked uncertain and you check the conversation. A duplicate screenshot in your chat is worse than asking you to look.
An existing draft is never overwritten. If the composer already has text in it, the send stops and tells you.
A generating answer is never interrupted. The queue waits for it to finish rather than cutting in.
Restricted pages are detected before injection. chrome://, the Web Store, the PDF viewer and the extension's own pages cannot be captured; the tool says so instead of failing silently.

Questions

Does it work with a free ChatGPT account?

Yes. It uses whatever the browser is signed in to. If the web page works, ShotThink works.

Will my screenshots be sent to your server?

No. There is no server. The image goes from your browser to chatgpt.com and nowhere else.

Why can't it capture WeChat or Excel?

A browser extension can only see browser content. For the whole desktop, the same author makes Mouse4, a Windows tool.

What happens if ChatGPT changes its page?

Sending pauses and tells you, rather than guessing. The selectors are redundant and the failure is visible, so an update can fix it quickly.

Do I need to keep a ChatGPT tab open?

Yes. It runs in the background and does not need to be in front, but closing it stops delivery.

Is Firefox supported?

No. The extension relies on Chromium's captureVisibleTab and scripting behaviour.
